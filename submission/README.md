# Telegram Designers submission

The approved recordings are [Desktop](../media/desktop.mp4) and [iPhone](../media/iphone.mp4), 81 seconds each.

The [English message](message.en.md) accompanies the source ZIP and both playable MP4s. A [Russian translation](message.ru.md) is provided for review. The messages use the final attachment names `SOURCE.zip`, `desktop.mp4` and `iphone.mp4`.

The project is a standalone browser prototype with synthetic chats, prepared analysis and simulated local sharing. No message has been sent to Telegram as part of preparing these files.

[Earlier recording variants](../media/alternatives/README.md) remain available for comparison.
