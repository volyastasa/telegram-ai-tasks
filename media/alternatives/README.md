# Earlier recordings

The featured [Desktop](../desktop.mp4) and [iPhone](../iphone.mp4) recordings run for 81 seconds each. They show clean UI, introduce the hint before dimming the background to 25%, then remove the dimming and hint in that order.

Matching JPG posters use the same basenames as the full walkthrough videos. English chapter captions for the clean walkthroughs are available for [desktop](desktop-clean.en.srt) and [iPhone](iphone-clean.en.srt).

All recordings show the standalone browser prototype with synthetic chats, prepared task analysis and simulated local sharing. They do not connect to a Telegram account. The featured recording sequence is documented in the [desktop](../desktop.storyboard.json) and [iPhone](../iphone.storyboard.json) storyboards.
